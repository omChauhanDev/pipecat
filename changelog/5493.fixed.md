- Fixed an exception raised by a `@job` handler (or an `on_job_request` override) never settling its job. The exception was logged by the task manager and nothing else happened, so no response was sent, the job stayed in the worker's active jobs, and a requester using the default `JobParams(timeout=None)` waited on `job()` or `job_group()` forever. An escaping exception is now logged with its traceback and settles the job as `JobStatus.ERROR`, so the requester raises `JobError`.
